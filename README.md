## 📚 Topics Covered

### 🔢 Arrays
A comprehensive collection of array problems covering:
- Basic operations: clone, reverse, rotate, swap elements, average
- Searching & sorting: find sorted, largest/second largest/smallest, max & min
- Number problems: even/odd, positive/negative, zero manipulation, palindrome
- Advanced: 2-Sum, unique triplets, merge sorted arrays, missing number, duplicate detection, occurrences
- Utility: count numbers, number length, plus one, target sum

### 🔗 Linked Lists
- **Singly Linked List** – insert, delete, traverse
- **Doubly Linked List** – bidirectional traversal and operations
- **Circular Linked List** – circular traversal
- **Reverse Singly Linked List** – in-place reversal
- **Traversal** – generic traversal techniques

### 📦 Queue
- **Queue** – basic FIFO queue implementation
- **Circular Queue** – fixed-size circular buffer
- **Dequeue (Deque)** – double-ended queue

### 🥞 Stack
- **Stack** – basic LIFO stack implementation
- **Reverse Stack** – reversing a stack using recursion

### 🔄 Recursion
- **Factorial** – recursive factorial computation
- **Fibonacci** – recursive Fibonacci sequence
- **Printing Numbers** – printing sequences using recursion

### 🌳 Tree
- **Binary Search Tree (BST)** – insert, search, delete
- **Tree Traversal** – inorder, preorder, postorder traversals

### 🪟 Sliding Window
- Sliding window technique for subarray/substring problems

### 🧩 OOP
- Object-Oriented Programming concepts in Python
